## About

Explore **23,097 printable coloring pages across 25 categories**. Grab your virtual crayons, color right in your browser — then watch your art come alive as a **time-lapse video** you can share, or print a crisp outline to color at home.

No sign-up. 100% free, forever.

## Features

- 🖍️ **Color online** — tap to fill, pick from the crayon palette, undo anytime. Works on phone & desktop.
- 🎬 **Time-lapse videos** — your whole session replays as a satisfying time-lapse, ready to share on TikTok or Reels.
- 🖨️ **Print-ready pages** — high-resolution outlines sized for standard paper.
- 🏫 **Classroom mode** — teachers create a class with one link; students color and submit to the class wall, no accounts needed.
- ⚔️ **Challenge mode** — send a challenge link and see both artworks side by side.
- 🎯 **Difficulty levels** — Easy, Medium, and Hard badges based on actual area counts.

## Development

The site is a single static `index.html` with no build step. To preview locally:

```bash
# open directly
open index.html

# or serve it
python3 -m http.server 8000   # then visit http://localhost:8000
```

Push to `main` and GitHub Pages redeploys automatically.
